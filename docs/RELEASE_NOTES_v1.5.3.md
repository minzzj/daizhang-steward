# v1.5.3 发布说明 / Release Notes — 功能去重：对话与调度统一到 AI 总控

> 发布日期：2026-10-31 · 版本：v1.5.3 · 基线：v1.5.2

## 1. 这次解决了什么

用户反馈：
1. "系统的调度功能"和"对话功能"重复，都是总调度；
2. "对话里面那些新建对话等功能用不了"。

v1.5.3 把重复入口合并，并修复/验证对话页交互：

### 1.1 去重：一个 AI 总控对话入口
- **系统页（/system）移除独立的超级总调度对话**：不再有第二个"对话/调度"输入框（此前面板为空、发送命令不响应，容易误以为坏掉）。
- 系统页改为**系统管理**页：保留两层结构、受管程序/插件、各 agent 模型与 Token、全部日志、危险动作；
  顶部新增**统一入口面板**：「打开 AI 总控对话 → /chat」+ 6 个快捷查询链接（查看系统状态/最近运行/产物/报告/配置/账本）。
- 快捷链接支持 `/chat?prompt=...`：打开 AI 总控后**自动发送该问题**并展示最终结果（发送后 URL 清理 prompt 参数）。
- **历史会话页（/chat/:id）降级为"运行详情（历史版）"**：移除独立的「与总调度对话」「＋新建项目」入口，只读展示历史记录，并显著提示"统一对话/调度入口在 AI 总控（/chat）"。
- 对话/调度/项目派发/审批现在只保留 **/chat（AI 总控）** 一个入口；系统页只做系统管理，运行证据看 `/runs/:id`。

### 1.2 对话页交互验证/修复
- 已逐项实测可用：**新建对话、切换历史对话、重命名、删除、记忆搜索/删除、快捷 chips、发送/流式回复、刷新恢复、审批按钮**（真实控制台 + E2E 双重验证）。
- 增加页面级错误提示（新建/重命名/删除/审批失败会在页面显示原因，不再静默无反应）。
- 系统页移除对话后，system.js 的 supervisor 初始化已做空值保护（不会因元素不存在而中断其它按钮脚本）。

## 3. 兼容性

- 旧 `/chat/:id` 路由保留（作为运行详情历史版），不再承担对话/调度入口；`/runs/:id` 为新版运行详情。
- 系统页 API 保留（supervisor messages/command），但页面不再暴露重复对话入口。
- 版本 1.5.3；控制台 health 返回 `1.5.3`。
