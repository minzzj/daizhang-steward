# v1.5.5 发布说明 / Release Notes — 点击无反应排查与修复

> 发布日期：2026-10-31 · 版本：v1.5.5 · 基线：v1.5.4

## 1. 排查结论（不是"告诉你哪里点"，是修了"点了没反应"）

针对"专项智能体点什么都没有反应"，逐页做了真实浏览器点击审计，定位到 3 类问题并修复：

### 1.1 智能体卡片：整卡点击无效（真实 BUG）
- 页面标题写着"点击卡片可展开详情"，但此前只有卡片里的「展开详情」按钮绑定了事件；**点卡片正文区域没有任何反应**。
- 修复：整张智能体卡片可点击展开/收起详情（链接/按钮/输入元素除外），并加指针样式；键盘/按钮方式仍可用。
- E2E 新增断言：「智能体卡片整卡点击可展开详情」。

### 1.2 页面脚本异常/控制台重启后点击无反应（真实场景）
- 控制台本地进程重启或后端异常时，旧页面会"看起来正常但所有操作无响应"（请求失败只在控制台里报错）。
- 修复：所有页面注入**运行时守护**：
  - 捕获页面 JS 错误 / 未处理 Promise → 页面底部显示明确错误条 + 「重新加载」按钮；
  - 每 6 秒探测 `/health`：版本或启动时间变化（控制台更新/重启）→ 显示"控制台已更新/重启，点击重新加载"；
  - 连接中断 → 显示"控制台连接中断"。
- 用户不再需要猜"为什么没反应"，页面会直接说明原因并一键恢复。

### 1.3 上一轮去重后的入口保持一致
- 智能体卡片保留「点名发任务 →」（`/chat?agent=<role>` 预选 + 独立智能体上下文）；
- `/system` 保持系统管理 + 统一入口（无重复对话）；
- 历史 `/chat/:id` 为只读运行详情。

## 2. 关于"直接借鉴 DeepSeek Harness"
- 专项智能体不是模仿交互壳：每个被点名的智能体**直接运行本机 DeepSeek Harness 代理进程**（`dsh --profile headless --json`），使用其真实工具/思考/产物/报告能力；代掌只做调度、隔离与呈现。
- 每个智能体独立工作区 + 独立历史（`.steward/chat/agents/<role>/`），总控上下文不进入，避免上下文污染/漂移。
