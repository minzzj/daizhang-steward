## 视觉与声音

- 色板：深空底 `#070B14`、核对青 `#66E3D2`、警示琥珀 `#FFB45C`、纸白 `#E9F1FA`、辅助灰 `#8FA3BD`。
- 截图处理：窗口卡 + 深色渐变压边；真实截图不重绘、不生成；每段一个画面任务。
- 节奏：每 2–4 秒有一个视觉变化；场景切点落在 BGM 小节线（2 秒/小节，120 BPM）。
- BGM：`tools/make_bgm.py` 用 Python/NumPy 合成，110 秒，无人声；`ffmpeg loudnorm` 到 -17 LUFS。
- 字幕：底部安全区，28px 上限、单行，不压 HUD。
