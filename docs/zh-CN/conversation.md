# 对话式总控与记忆（v1.5.1）

> 一个入口控制全部：像和 ChatGPT 对话一样对「AI 总控」说话，它自己去系统里查、自己干，过程和结果（思考/工具/产物/报告/数据）全部显示在对话里。

## 1. 怎么用

打开 `http://127.0.0.1:4180/chat`：
- **直接说**：例如「系统现在怎么样？」「最近的 run 列表」「产物在哪」「把最新的报告给我看」「这个项目 Token 花了多少」「帮我写一个报价单页面」。
- 总控会自己判断：查询类直接查系统并回复（0 token / 极低成本）；任务类自动执行（小任务用 Harness 代理，项目类自动派发给专项智能体），过程中实时显示思考/工具/产物/报告/数据。
- 你只需要在**危险动作**（删程序/插件、付款、对外发送、法务签署）时点批准/驳回；其他都交给 AI。

## 2. 一个入口能查/能控什么

- **系统**：受管程序/插件、服务状态、日志、审计
- **项目/运行**：会话列表、run、步骤状态、事件时间线、每轮摘要
- **产物**：文件列表、内容预览（HTML/Markdown/JSON/图片）、下载
- **报告**：每步 agent 报告 + run 汇总报告（Markdown 渲染）
- **数据**：Token 输入/输出/缓存/总计、工具调用分布、耗时、步骤、预算
- **配置/模型**：当前配置摘要、模型/密钥引用（只显示掩码）
- **账本/收款**：收款请求、到账、账本 6 要素
- **智能体**：全部 agent 状态、Harness 元数据、最近执行记录

## 3. 记忆

- **对话历史**：多会话（新建/切换/重命名/删除），持久化保存，刷新/重启不丢；打开即恢复上次对话。
- **长期记忆**：自动从对话与执行中抽取（用户偏好、项目事实、决策、run 摘要、交付物引用），可在右侧「记忆」面板查看/搜索/删除；回复时会自动引用相关记忆。
- **短期上下文**：最近消息 + 本轮工具结果；超出限制自动摘要。
- **数据**：`.steward/chat/`（gitignore，本地保存）。

## 4. 数据源说明

- 真实数据：真实 Harness 运行的产物/报告/Token/事件。
- 演示数据：内置 demo provider 用于 UI/边界测试。
- 页面顶部显示 `数据源：真实/演示/混合`；演示卡片带「演示」标识。测试保留真实样本 + 假数据混合。

## 5. 成本控制

- 简单查询由规则/查询工具直接回答，不调用模型；
- 任务类才用 Harness 代理，单步 token/超时上限可配（默认单步 200 万 tokens）；
- 对话里显示每步实际 Token 用量。

## 6. 安全

- 危险动作通过内联审批卡确认，AI 不代签、不自动付款/外发；
- 只监听 127.0.0.1；写操作需要 token；密钥不注入 Harness；
- 所有动作/审批/工具调用写入审计与对话记录。

## 7. 呈现规则（v1.5.2）

- 默认只显示：**你输入的内容 + 思考过程（折叠）+ 最终结果**；
- 「思考过程」展开后：思考分块、工具调用（单卡：状态/耗时/结果预览）、查询数据、记忆引用；
- 报告/产物作为**交付物卡片**显示在最终结果下方（最多 3 个，其余收起）；
- 审批卡与错误**始终可见**，不可折叠；
- 等待审批 = 暂停（不是失败），批准后继续执行并在对话里推送进展；
- 纯查询不产生「产物/报告」级记忆噪音。
