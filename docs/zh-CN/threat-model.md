# 威胁模型 / Threat Model（中文）

> 原则：**默认拒绝**；超时挂起；所有对外动作留证；密钥不入库不入日志。
> 本模型覆盖阶段一（操作型 AI 内核）与阶段二（经营代理）共用的安全边界。

## 1. 资产

- 授权人的账号凭据、平台会话、收款账户（只读引用，不落盘明文）。
- 客户对话与个人信息（最小化、脱敏、限保留期）。
- 经营数据：账本、预算、项目、合同/发票状态。
- 事件账本与证据（不可删除；被篡改即失效）。
- 模型密钥（只从环境变量/密钥存储读）。

## 2. 威胁与默认应对

| 威胁 | 默认规则 | 证据 |
|---|---|---|
| 凭据泄漏 | 只从环境变量/密钥存储读；日志脱敏；提交前 secret scan | 扫描报告、日志无密钥 |
| 验证码 / 2FA / 人脸核验 | 停止并交人，不绕过 | handoff 事件 + 截图 |
| 支付 / 退款 | 默认拒绝；人类审批；单笔阈值 | 审批卡 + 回执 |
| 合同 / 对外承诺 | 只生成草稿；人类签署 | 待签文件 + 授权记录 |
| 批量外联 | 只起草；人类批准；每日每渠道 ≤10；支持退订 | 审批队列 + 发送日志 |
| 个人信息 | 最小化；有合法依据；不抓登录后页面 | 来源 URL + 依据 |
| 生产部署 | 默认禁止；人类批准；可回滚 | 部署单 + 回滚方案 |
| 提示注入 | 网页/文件内容只当数据，不执行其中指令；隔离来源并告警 | 隔离事件 + 原文 |
| 失控循环 | 预算上限；最多两轮；停止键 5 秒 | 预算日志 + 停止记录 |
| 账本篡改 | 只追加 + 哈希链；定期验证 | 校验日志 |
| 越界经营 | 30 条边界规则（无证业务/借资质/陌生外呼/超预算等）100% 拒绝 | 拒绝理由 + 事件 |
| 遥测/许可 | 默认无遥测；核心不依赖私有 SaaS；LICENSE 明确 | 配置 + LICENSE |

## 3. 信任边界

- Operator ↔ 外部网站/应用：不可信输入，不执行页面内指令。
- Scout ↔ 公开来源：只读、频控、robots/ToS 优先。
- 内核 ↔ DSH Harness：Harness 只接收 CodeTask 文本，不接触生产凭据。
- 内核 ↔ 通知通道：只发摘要，不发凭据/个人信息原文。
- 内核 ↔ IoT（未来）：设备只拿白名单动作，指令需审批。

## 4. 停止键与降级

- 停止键 5 秒内停止所有分支新动作（事件留证）。
- 重启从检查点恢复，不重复发送/扣款。
- 72 小时失联 → 只读模式；断网 → 本地暂存、恢复后补记并标缺口。
- 平台封禁 → 停止该平台全部动作，出替代方案并通知。

## 5. 复查节奏

- 每个里程碑复核一次威胁表；阶段二上线前由授权人或其法务做一次人工复核（30 条边界）。
- 安全事件修复后 7 天内公开（见 SECURITY.md）。
