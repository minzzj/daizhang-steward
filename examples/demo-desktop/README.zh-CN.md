# demo-desktop · 真实桌面演示程序（Python 标准库 tkinter）

> 状态：M0 演示素材，用于 **A3 真实桌面验收**（真实 Windows 窗口 + 真实键鼠 + 截图 + UIA）。
> 只使用 Python 标准库（`tkinter`、`json`、`argparse`、`pathlib`、`datetime`），**无第三方依赖、不访问网络**。

## 1. 环境要求

- Windows + Python 3.11（官方安装包自带 `tkinter`；Linux/macOS 需系统安装 Tk 后也可运行）。
- 需要可交互桌面环境（无桌面/无显示的 CI 请改用第 6 节的 `--self-test`，真实窗口验收只在本地跑）。

## 2. 运行

```bash
# 默认输出到 examples/demo-desktop/out/project.json（目录自动创建）
python main.py

# 指定输出文件（相对当前工作目录）
python main.py --out out/project.json

# 查看帮助
python main.py --help
```

窗口标题固定为 **`代掌演示表单`**（自动化定位窗口时以此为准）。关闭窗口即退出程序。

## 3. 界面说明

| 控件 | 名称 | 说明 |
|---|---|---|
| 输入框 | 客户名称 | **必填**；输入后按 Enter 触发保存 |
| 输入框 | 项目名称 | **必填**；输入后按 Enter 触发保存 |
| 多行文本框 | 备注 | 可选；Enter 为换行，`Ctrl+Enter` 触发保存 |
| 按钮 | 保存 | 校验通过后写入 JSON；失败时状态标签显示「校验失败：…」且**不写文件** |
| 按钮 | 校验 | 只校验必填项，不写文件；通过时显示「校验通过：可以保存。」 |
| 按钮 | 清空 | 清空三个字段与状态标签 |
| 状态标签 | — | 显示「就绪 / 已保存：<路径> / 校验失败：客户名称为空 / 校验失败：项目名称为空 / 校验通过：可以保存。 / 已清空 / 保存失败：…」 |

保存的 JSON 字段（虚构示例）：

```json
{
  "customer": "示例客户",
  "project": "官网改版",
  "note": "虚构演示数据，第一行\n第二行",
  "saved_at": "2026-10-25T16:30:00+08:00"
}
```

- `customer` / `project` / `note` 会去除首尾空白；`saved_at` 为带本地时区偏移的 ISO 8601 时间。
- 默认写入 `examples/demo-desktop/out/project.json`；`out/` 已在仓库 `.gitignore` 中忽略，文件不会被提交。

## 4. 键盘操作（供真实键鼠自动化）

- `Tab` / `Shift+Tab`：在控件之间顺序移动焦点（客户名称 → 项目名称 → 备注 → 保存 → 校验 → 清空）。
- 客户名称、项目名称输入框内按 `Enter`：保存。
- 备注文本框内按 `Ctrl+Enter`：保存（`Enter` 保留为换行）；备注内按 `Tab` 移焦点到「保存」按钮，`Shift+Tab` 回到「项目名称」。
- 按钮获得焦点后按 `Space` 或 `Enter` 可激活；鼠标左键点击按钮同样有效。
- 窗口启动后焦点默认在「客户名称」输入框，可直接键入。

## 5. 手工验收 5 步

> 前置：在 `examples/demo-desktop` 目录下执行 `python main.py`。以下每步都要求窗口真实可见、真实操作并留存截图（命名参考 `docs/images/README.md`，如 `A3-demo-desktop-save-03.png`）。

1. **打开**：运行 `python main.py`，确认出现标题为「代掌演示表单」的窗口，状态标签显示「就绪：…」，焦点在客户名称输入框。
2. **填表**：客户名称输入任意内容（如 `示例客户`），`Tab` 到项目名称输入 `官网改版`，备注填 `虚构演示数据`；输入过程应正常响应键盘。
3. **保存**：点击「保存」按钮（或在项目名称输入框按 `Enter`），状态标签出现「已保存：…」；打开 `out/project.json`，确认 `customer` / `project` / `note` / `saved_at` 四个字段与输入一致，截图。
4. **校验**：点击「清空」后直接点「校验」或「保存」，状态标签应显示「校验失败：客户名称为空」，**且 `out/project.json` 保持上一步内容不被覆盖**；再只填客户名称点「校验」，应显示「校验失败：项目名称为空」。截图。
5. **截图留证**：补全两项必填后保存成功，截取包含窗口标题、字段内容与状态标签的完整窗口截图，保存到验收证据目录；关闭窗口，确认进程正常退出。

## 6. 无 GUI 自检（CI / 自动化可用）

```bash
python -m py_compile main.py   # 语法检查
python main.py --self-test     # 无窗口自检：必填校验规则、字段裁剪、JSON 落盘与字段完整性
```

`--self-test` 会按 `--out` 指定的路径写一个 JSON 再核验并**自动删除**该文件（可能保留空目录），不会打开窗口；退出码 `0` 表示全部通过。可配合 `--out` 把自检文件放到临时目录：

```bash
python main.py --self-test --out out/self-test.json
```

## 7. 已知限制

- **DPI 缩放**：程序未启用高 DPI 感知，Windows 缩放 125%/150% 时窗口可能被系统拉伸发虚；真实键鼠自动化若按坐标点击需按实际缩放换算，或优先使用键盘（Tab/Enter）操作。
- **窗口焦点**：真实键鼠输入要求窗口在前台且获得焦点；自动化脚本启动后应先激活标题为「代掌演示表单」的窗口。
- **数据**：单文件覆盖写（每次保存覆盖上一次）；无加密、无并发写保护；仅本地演示用途。
- **平台**：字体优先使用 Windows 中文字体；在无中文字体的环境中文可能显示为方框。
- **不可用模态弹窗**：校验失败/成功只更新状态标签，不弹 `messagebox`，便于真实自动化与截图断言。
